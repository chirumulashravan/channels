# IPTV Playlist Output

This workspace contains multiple projects, but the ready-to-use IPTV playlist is generated in the `channels` project.

## Final M3U file to use

Use this file as the end-of-pipeline output:

- Local file: `channels.m3u`
- Raw copy-paste URL (GitHub): `https://raw.githubusercontent.com/chirumulashravan/channels/main/channels.m3u`

This is the master playlist generated by the updater script. It combines the source channels into a single Extended M3U file and is the main file to load in Kodi or another IPTV client. Copy the raw URL directly into your IPTV app or player.

## Related generated files

- `channels/country_playlists/*.m3u` — country-specific playlists
- `channels/playlists/**/combined.m3u` — source-folder combined outputs
- `channels/Unclassified.m3u` — channels without a clear country match

## Source and generation

The master playlist is generated from the configured source(s) defined in `channels/playlist_sources.json` and assembled by `channels/scripts/update_playlist.py`.

If you want the final, usable playlist for end-user consumption, choose `channels/channels.m3u`.
